
# OWASP Juice Shop - DevSecOps

## 1. Project Description

This project aims to build an automated DevSecOps pipeline around OWASP Juice Shop.

## 2. Project Objectives

- Automate application builds and tests.
- Integrate automated security scans.
- Deploy the application using Kubernetes.
- Monitor the application using Prometheus and Grafana.
- Send notifications through Discord.

## 3. Tools and Technologies

- Git
- GitHub
- Podman
- Podman Compose
- GitHub Actions
- Semgrep
- Gitleaks
- Trivy
- npm audit
- Kubernetes (Minikube)
- Prometheus
- Grafana
- Discord
